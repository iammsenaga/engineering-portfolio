# Hand Cursor — Webcam gesture control

**Original project year:** 2026  
**Role:** Developer  
**Technologies:** Python, JavaScript, MediaPipe, Windows APIs  
**Source:** Private experiment

[All projects](../README.md)

## The idea

Use a webcam and hand gestures to control the Windows mouse cursor. Index-finger movement moves the pointer, and a thumb–index pinch triggers a click.

## What I built

- A browser camera and hand-tracking interface.
- A local Python bridge to Windows cursor controls.
- Adjustable sensitivity and response.
- Keyboard controls to pause and enable cursor interaction.

The camera view and hand tracking run in the browser, while cursor actions are handled locally. This is an interaction experiment rather than a published accessibility-certified product. Its source has not been released publicly.
